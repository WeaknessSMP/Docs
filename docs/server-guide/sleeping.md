# Sleeping
## Why it Happens?
After 3 hours of inactivity, the server will enter sleeping mode.<br>
This is due to a limitation with PixelForge.<br>
## During Sleeping Mode
During the sleeping mode, the icon will be different. It looks like this:<br>
<img width="64" height="64" alt="sleeping" src="https://github.com/user-attachments/assets/63839985-424a-4053-9d04-12212917e1a0"/><br>
# How to Fix?
To fix this, just join the server. It will automatically start up.<br>
Please wait around 2 minutes for all the plugins in the server to set up.<br>
Then, join the server again and it will let you in!
