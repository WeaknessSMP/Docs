# Admin Guide: Moderation
This guide shows all the commands for admins. There are 2 methods to moderating with admins.<br>
<br>
## Via Menu (simplest)
Type `/admin`, go to Moderation, select a player, and click an action.
<br>
## Via Commands (quicker)
### Jail
Jailing is one of the first things to do. To use type:<br>
`/jail {player} bedrock_prison {time (e.g 3h)}`

### Kick
To kick, type<br>
`/kick {player}`

### Temporary Ban
To temporarily ban someone, type:<br>
`/tempban {player} {time}`

### Permanant Ban
This is very similar to temporary ban. Type:<br>
`/ban {player}`
