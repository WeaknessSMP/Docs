# Admin Guide: Logging Warnings
## Intro
This guide shows how to log warnings.<br>
You must log warnings in [our spreadsheet](https://docs.google.com/spreadsheets/d/18Q2Y4Ej8fRhTPHLD8biQbclU6gB7cQ0_oyb-LVGAotE/edit?usp=sharing)<br>
## Finding the Player
Find the player's username from the list in the first column.<br>
::: details I can't find it!
Please add the username to the Player Username column.
:::
## Setting and Logging the Data
Set the warnings in the next column.<br>
If it's a major punishment-worthy exploit, and it's their first time caught, please set the warnings to 12.<br>
Otherwise, please add 1 to the warnings.<br>
### **After, please set the last warning reason (last column)**
::: tip Examples
- X Raying
- Speed Hacking
- Fly Hacking
:::
## Giving Punishments
Now, to give the right punishment, please refer to the table below.<br>
_The warning severity column tells you if it's a major or minor punishment. After the person reaches 21 warnings, they should be Permabanned and it will say that in the warning severity column._

|Times Punished |Punishment|
|---| :---: |
|1|Kick|
|2|Temporary Jail (30m)|
|3|Temporary Ban (2h)|
|4|Clear Everything + Temporary Ban (1d)|
|5|Clear Everything + Temporary Ban (7d)|
|6|Clear Everything + Temporary Ban (14d)|
|7|Permanent Ban|
